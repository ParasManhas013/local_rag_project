## 🧩 Master Template – PPT Generation

The **`Master-Template` branch** serves as the **base template for automatic PowerPoint (PPT) generation** in this project.

It includes:
- Document ingestion & summarization pipeline
- LLM-based slide outline generation
- PPT creation using `python-pptx`
- Ready-to-extend structure for themes, layouts, and speaker notes

Use this branch as the **starting point** if your goal is to generate presentations from documents using RAG.
